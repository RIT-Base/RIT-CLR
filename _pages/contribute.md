Terima kasih atas minat Anda untuk berkontribusi pada proyek **RIT Curated Learning Resources (CLR)**. Proyek ini digerakkan oleh komunitas, dan setiap bantuan sangat kami hargai. Ada dua cara utama untuk berkontribusi: melalui **konten** atau **pengembangan website**.

## 1. Berkontribusi Konten

Punya rekomendasi artikel, video, kursus, atau sumber belajar lain yang berkualitas? Kami sangat senang menerimanya! Untuk menjaga kualitas dan format, pastikan Anda mengikuti templat yang sudah kami sediakan.

**[Akses Template Kontribusi di Sini](https://github.com/RIT-Base/RIT-CLR/blob/UI-jekyll/_posts/2025-10-14-contribute.md?plain=1)**

**[Akses Cara Penulisan Markdown di Sini](https://github.com/RIT-Base/RIT-CLR/blob/UI-jekyll/_posts/2025-10-12-template.md?plain=1)**

**[Akses Tampilan Markdown di Sini](https://rit-base.github.io/RIT-CLR/misc/template/)**

Setelah Anda menyiapkan materi sesuai templat, Anda bisa mengirimkannya melalui salah satu dari dua cara berikut:

### via Discord (Direkomendasikan)
Cara tercepat untuk mengirimkan dan berdiskusi dengan tim kami adalah melalui server Discord RIT.

- **Kirimkan di *channel*:** [#📄-clr-submission](https://discord.com/channels/1282118759623954515/1427579020563841085)

### via Google Form
Jika Anda tidak menggunakan Discord, Anda juga bisa mengirimkan kontribusi melalui Google Form.

- **Kirimkan di *GForm*:** [RIT CLR Submission Google Form](https://docs.google.com/forms/d/e/1FAIpQLSdtUIZrJkRBokJBGkFNZoNI-jwczj-vo91xwIvXxxoXVgSfbw/viewform?usp=header)

## 2. Berkontribusi pada Pengembangan Website

Jika Anda tertarik untuk membantu mengembangkan fungsionalitas, memperbaiki *bug*, atau meningkatkan tampilan website RIT CLR, Anda bisa langsung berkontribusi pada repositori kami.

### Repositori GitHub
Semua kode sumber dan isu terkait pengembangan website dikelola di sini. Jangan ragu untuk membuat *pull request* atau melaporkan isu.

- **Kunjungi Repositori:** [https://github.com/RIT-Base/RIT-CLR](https://github.com/RIT-Base/RIT-CLR)

### Dokumentasi Teknis
Website RIT CLR dibangun menggunakan *theme* Jekyll **Minimal Mistakes**. Jika Anda ingin memahami cara kerja *layout*, komponen, atau fitur lainnya, silakan merujuk pada dokumentasi resminya.

- **Baca Dokumentasi Minimal Mistakes:** [https://mmistakes.github.io/minimal-mistakes/docs/quick-start-guide/](https://mmistakes.github.io/minimal-mistakes/docs/quick-start-guide/)
